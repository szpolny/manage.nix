# Documentation

manage.nix is currently alpha software. Start with installation, then deploy a
revision and configure health checks before managing more machines.

- [Installation](installation.md): set up the server, enroll an agent, and upgrade.
- [Deploying](deploying.md): connect Git, deploy revisions, roll back, and update.
- [Services](services.md): inspect machine service states and freshness.
- [Configuration](configuration.md): databases, secrets, health checks, and macOS.
- [CLI reference](cli.md): commands for machines, repositories, and deployments.
- [Development](development.md): local setup, database queries, tests, and releases.

The [project overview](../README.md) introduces the product and its current release.
